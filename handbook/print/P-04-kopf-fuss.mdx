# P-04 · Jede Seite trägt Kopf und Fuss

## Regel

Wiederhol auf jeder gedruckten Seite oben Firma, Dokument und Nummer und unten „Seite 2 von 3“ und das Druckdatum. Tabellen wiederholen ihren Kopf auf jeder Seite; eine Zeile wird nicht über zwei Seiten getrennt.

## Warum

Gedruckte Seiten werden getrennt, geheftet, verlegt. Eine Seite ohne Kopf gehört zu nichts mehr; ohne Seitenzahl merkt niemand, dass eine fehlt. Das Druckdatum sagt, wie aktuell der Stand ist.

## Details

- CSS: `thead { display: table-header-group }`, `tr { break-inside: avoid }`.
- „Gedruckt 29.10.2026 10:30“, nicht nur das Datum.

## Übertragen

- Dompdf/Browsershot: Kopf und Fuss als feste Elemente oder über die Header/Footer-Optionen; Seitenzahlen bei Dompdf über `$canvas->page_text(…, "Seite {PAGE_NUM} von {PAGE_COUNT}", …)` bzw. `pageNumber`/`totalPages` (Chrome).
- Nova-Index drucken ist kein Bericht: einen eigenen Druck-Endpunkt bauen.
