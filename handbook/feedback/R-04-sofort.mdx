# R-04 · Sofort zeigen wenn der Weg zurück sicher ist

## Regel

Umschalten, Status setzen, Zuweisen, Fertig melden wirken sofort (optimistisch) und bieten „Rückgängig“. Scheitert der Server, kehrt der alte Wert sichtbar zurück und eine Meldung sagt warum. Nur Endgültiges (löschen, versenden, abrechnen) fragt vorher (S-06).

## Warum

Warten auf den Server bei jedem Haken macht Software zäh; Linear fühlt sich darum so schnell an. Rückgängig ist sicherer als eine Rückfrage, die man reflexhaft wegklickt.

## Details

- Optimistisch nur, wenn der Server in der Regel zustimmt und der Weg zurück vollständig ist.
- Der zurückgenommene Wert bekommt einen Eintrag im Verlauf (S-09).

## Übertragen

- Nova: Aktionen auf Zeilen mit `->withoutConfirmation()` für Umkehrbares; eine Gegen-Aktion als Rückgängig.
- Inertia/Livewire: Wert lokal setzen, Anfrage senden, bei Fehler zurücksetzen und melden.
