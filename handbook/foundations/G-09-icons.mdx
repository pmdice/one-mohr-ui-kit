# G-09 · Icons begleiten Text

## Regel

Stell ein Icon neben ein Wort. Allein steht ein Icon nur für allgemein bekannte Zeichen (Schliessen, Suche, Weitere Aktionen) und dann mit Beschriftung für Screenreader (`aria-label`) und einem Tooltip. Dasselbe Icon heisst überall dasselbe.

## Warum

Icons sind schneller zu erkennen, wenn man sie kennt, und ein Rätsel, wenn nicht. Ein Stern kann Favorit, Wichtig oder Bewertung heissen. Mit dem Wort daneben ist es eindeutig, und das Icon hilft beim nächsten Mal beim Wiederfinden.

## Details

- Icons dekorativ mit `aria-hidden="true"`, wenn das Wort daneben steht.
- Eine Bibliothek (lucide) und eine Grösse pro Dichte (16 px kompakt).
- In der Werkstatt nie Bedeutung nur im Icon (W-03).

## Übertragen

- Nova: Actions haben immer einen Namen (`name()`) und werden als Text im Aktionsmenü gezeigt – so bleibt es. Icons gibt es in eigenen Feldern, Tools und Karten; dort gilt die Regel wie hier.
- Eine Icon-Liste mit Bedeutung führen (siehe *Komponenten*), damit niemand ein neues Icon für dasselbe wählt.
