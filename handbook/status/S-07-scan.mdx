# S-07 · Ein Scan gibt eine eindeutige Rückmeldung

## Regel

Behandle einen Scan wie jeden Wechsel – ein, wenn der Zettel nicht hier liegt, aus, wenn er hier liegt – und antworte gross in einem Satz mit Kennung, Richtung und Station.

## Warum

Am Scanner schaut man auf das Werkstück, nicht auf den Bildschirm. Ein doppelt gelesener Code darf den Zettel nicht gleich wieder ausscannen.

## Details

- „26100013 – 1/4 eingescannt in Guss“; ein erneuter Besuch wird gezählt („2. Durchlauf“).
- Unbekannter Code oder abgeschlossener Zettel: Fehlermeldung mit dem gelesenen Code bzw. dem Grund.
- Derselbe Code innerhalb von 3 Sekunden: „Schon erfasst“, nichts passiert.

## Übertragen

- Hand-Scanner tippen wie eine Tastatur und senden Enter – ein normales Eingabefeld mit Submit genügt.
- Die Doppel-Sperre gehört auch ins Backend (gleicher Code, gleiche Station, wenige Sekunden).
