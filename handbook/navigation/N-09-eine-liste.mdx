# N-09 · Eine Liste, ein Menüeintrag

## Regel

Setz jede Liste genau einmal ins Menü; gefilterte Ansichten gehören in die Liste oder eingerückt darunter.

## Warum

Zwei Menüeinträge für dieselben Objekte lassen offen, welche Liste die richtige ist – man weiss nie, ob man alle oder nur einen Teil sieht.

## Details

- „Von mir erstellt“, „Offen“ usw. sind Ansichten derselben Liste (Segment-Schalter, N-11).
- Ist eine Ansicht so wichtig, dass sie ins Menü gehört, steht sie eingerückt unter ihrer Liste – nie in einer anderen Gruppe.
- Eine Ansicht ist ein Filter auf dieselbe Abfrage, keine eigene Seite mit eigener Logik.

- In Nova: statt einer zweiten Ressource eine Lens oder einen Filter verwenden.
