# Komponenten

Jede Komponente des Kits mit ihrem Zweck und den Regeln, die sie umsetzt. Ein Klick auf eine Regel führt zu ihrer Seite mit dem lebendigen Beispiel. Wer in Nova oder einem anderen Stack baut, sucht hier die Regel und überträgt das Verhalten, nicht den Code.

Ein Test hält die Liste vollständig: Eine neue Komponente ohne Eintrag lässt die Tests scheitern.
