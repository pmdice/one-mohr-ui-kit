## Review Focus

1. **Code 128 korrekt:** jede Tabellenzeile 11 Module (Stopp 13), Balken-Summe gerade, Prüfsumme „ABC“ = 1. → Test Task 1.
2. **Zeichen ausserhalb von Code B** (Umlaut, Tab) → klarer Fehler, kein kaputter Code. → Test Task 1.
3. **CSV:** Semikolon, Anführungszeichen, Zeilenumbruch im Wert, BOM, führende Nullen, `null` → leer. → Test Task 2.
4. **Dateiname:** Schrägstrich, Doppelpunkt, Leerzeichen. → Test Task 2.
5. **Seitenzahl** in der Vorschau stimmt mit der Anzahl Blätter. → Test Task 3.
