# Eingaben (Teil 6) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Eingabe-Bausteine nach E-01–E-10 (Zahl, Geld, Datum, Checkbox, Schalter, Radio/Segmente, Datensatz-Verknüpfung, Dateien, Zeichenzähler), eingesetzt in bestehenden Stellen, mit Handbuch und Beispiel.

**Architecture:** Neue Komponenten unter `components/inputs/`, reine Lese-/Schreibfunktionen in `components/inputs/parse.ts`. `Combobox` erhält `onCreate` und `recent`. Handbuch unter `handbook/inputs/`.

**Tech Stack:** wie Teil 0–5.

**Spec:** `docs/superpowers/specs/2026-10-29-inputs-design.md`

## Global Constraints

- Nur Tokens; Guard-Test; Katalog-Test (jede neue Komponente in `handbook/catalog.ts`).
- de-CH: Tausender `’`, Dezimalpunkt, Datum `TT.MM.JJJJ`, Wochen ab Montag.
- Geld nur als ganze Rappen (`number`, ganzzahlig).
- Regeltexte Deutsch, Code Englisch.

## Review Focus

1. **Rundung und Gleitkomma:** „0.1“ + „0.2“ Rappen-Lesen → 10 + 20 = 30; „19.99“ → 1999 (nicht 1998). → Test Task 1.
2. **Kalender und Monatsenden:** 31.01. + 1 Monat (Bild ab) → 28./29.02.; Schaltjahr 29.02.2028 gültig, 29.02.2027 nicht. → Test Task 1/3.
3. **Fokus nach Kalender:** Escape oder Auswahl → Fokus zurück im Textfeld. → Test Task 3.
4. **Upload entfernen während er läuft:** Abbruch-Signal wird ausgelöst, Datei verschwindet, andere laufen weiter. → Test Task 5.
5. **Nutzer tippt, Wert von aussen ändert sich:** Feld überschreibt die laufende Eingabe nicht, solange es fokussiert ist. → Test Task 2.

---

### Task 1: parse.ts
- Tests für `parseNumber`, `formatNumber`, `parseMoney`, `formatMoney`, `parseDate`, `formatDate`, `weekday`, `formatBytes` mit den Fällen aus der Spec und RF 1/2.

### Task 2: NumberInput, MoneyInput, Textarea-Zähler
- Tests: liest „1,5“ → onChange(1.5) beim Verlassen, zeigt „1.5“; Einheit sichtbar und Teil der Beschreibung; unlesbar → aria-invalid + Grund; Pfeile ± Schritt in Grenzen; Fremdwert während Fokus überschreibt nicht (RF 5); MoneyInput „1234.5“ → 123450, zeigt „1’234.50“; Textarea-Zähler erst ab 80 %.

### Task 3: DateInput + Calendar
- Tests: „morgen“ → ISO; Wochentag sichtbar; ungültig → Grund; Kalender öffnet auf gewähltem Tag, Pfeile/Bild ab/Enter wählen, Escape → Fokus zurück (RF 3); min/max ausserhalb nicht wählbar.

### Task 4: Checkbox, Switch, RadioGroup; Einsatz in DataTable und WorkshopTablet
- Tests: Checkbox `mixed` setzt `indeterminate`; Switch `role=switch` + `aria-checked`; RadioGroup Pfeiltasten, roving tabindex; DataTable-Tests bleiben grün.

### Task 5: Combobox onCreate/recent, RecordPicker, FileDrop
- Tests: „… neu anlegen“ nur ohne exakten Treffer, ruft onCreate(query); recent bei leerer Suche; RecordPicker zeigt Link zum gewählten; FileDrop: Typ/Grösse abgelehnt mit Grund pro Datei, Fortschritt, Entfernen bricht ab (RF 4).

### Task 6: Handbuch E-01–E-10, Beispiel, OrderForm, Katalog
- `handbook/inputs/` (rules.ts `INPUT_RULE_GROUPS`, examples, MDX), `allRules.ts` + `rules.test.ts`, Einleitung, Katalog-Einträge, Beispiel `components/inputs/examples/PositionEntry` (+ Story, Test), OrderForm: dueDate `DateInput`, qty `NumberInput unit="Stk." decimals={0}`, photos `FileDrop` (Form-Tests bleiben grün).
